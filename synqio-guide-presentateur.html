Infrastructure & technique

À utiliser si des questions techniques précises sont posées (sécurité, intégration, scalabilité).

Architecture globale

Frontend

  • Application web single-page (HTML/JS/Tailwind CSS)
  • Accessible depuis n'importe quel navigateur
  • Pas d'installation client requise
  • Interface responsive (desktop + tablette)

Backend

  • API Python (FastAPI) — performant et scalable
  • Base de données SQLite persistante sur volume dédié
  • Authentification JWT (tokens sécurisés)
  • Rate limiting et protection brute force

Hébergement

  • Railway.app — cloud infrastructure EU
  • HTTPS/TLS sur toutes les connexions
  • Volume persistant pour les données utilisateurs
  • Déploiement continu (mises à jour sans interruption)

IA & APIs tierces

  • Anthropic Claude — génération texte fiches
  • OpenAI DALL-E 3 — génération images produit
  • Amazon SP-API — intégration Seller Central (en cours de certification)
  • Tous les fournisseurs sont SOC 2 Type II certifiés

Sécurité des données

  • Isolation des comptes : chaque client voit uniquement ses propres données.
  • Chiffrement en transit : HTTPS/TLS sur toutes les API calls.
  • Mots de passe : hashés avec bcrypt (standard industrie), jamais stockés en clair.
  • Tokens JWT : expiration automatique (7 jours), révocables côté serveur.
  • Données IA : les données produit envoyées à Claude/DALL-E ne sont pas utilisées pour entraîner les modèles (accords enterprise avec Anthropic et OpenAI).

Amazon SP-API — statut

⚠️
En cours de certification : L'application SynqIO est enregistrée sur Amazon Developer Portal (Sandbox, ID : amzn1.sp.solution.5d19a782-61fd-4660-a714-959b46c28401). La certification production est en cours de revue Amazon. Une fois validée : connexion directe au compte Seller Central pour import automatique des fiches.

En attendant : Export via fichier Excel Seller Central — importation manuelle par le client.

Scalabilité

  • Architecture stateless : le backend peut être scalé horizontalement sans modification.
  • Jobs asynchrones : les générations tournent en tâches de fond — pas de timeout même sur de gros catalogues.
  • Multitenancy : conçu pour gérer plusieurs agences et marques sur la même instance.
  • SLA cible : 99.5% uptime (Railway garantit 99.9% sur l'infrastructure).
